# Mokesčių naujienos: prototipas

Interaktyvus Mokesčių SUFLERIO „Mokesčių naujienų“ skilties prototipas.

**Peržiūra:** https://richkus.github.io/mokesciu-naujienos/

Apačioje kairėje esantis perjungėjas „Dabartinė / Panel / Nauja“ (arba klavišas **V**) rodo tris versijas:

- **Dabartinė** - esama skiltis su patobulinimais: „Susipažinau“ checkbox'as, tab'ai Neperskaitytos / Visos / Perskaitytos, info ikonėlė vietoj ilgo teksto.
- **Panel** - ta pati esama skiltis, bet naujiena atsidaro šoniniame skydelyje dešinėje, virš sąrašo.
- **Nauja** - skiltis kaip inbox: kairėje sąrašas, dešinėje atidaryta naujiena.

Naujienos ir datos yra pavyzdiniai duomenys. Pažymėjimai saugomi tik jūsų naršyklėje.
